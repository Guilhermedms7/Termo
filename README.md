# Termo

Jogo de palavras para navegador, inspirado no Termo. A cada rodada, tente descobrir palavras de cinco letras usando as pistas de cor: verde para letra na posição correta, amarelo para letra presente em outra posição e cinza para letra que não pertence à palavra.

## Modos de jogo

- **Termo:** descubra uma palavra.
- **Dueto:** jogue com duas palavras ao mesmo tempo.
- **Quarteto:** jogue com quatro palavras ao mesmo tempo.

Cada palavra pode ser tentada em até seis rodadas.

## Tecnologias

- HTML
- CSS
- JavaScript
